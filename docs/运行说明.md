# 编译与运行

我们的正式源码目录是 `~/code/mission8/EU3D`；远端进入实际上传的项目目录。不要在 `others/` 或历史快照里修改我们的代码。

## 编译

需要 MPI C++ 编译器、CUDA Toolkit（含 nvcc）和可用 NVIDIA GPU。`include/ComputeConfig.hpp` 应为 `use_cuda = true`、`enable_dlb = false`。

本机 RTX 3050 / CUDA 12.5：

```bash
cd ~/code/mission8/EU3D
make -j2
```

A800 / CUDA 11.8，在项目根目录执行：

```bash
export CUDA_HOME=/usr/local/cuda-11.8
export PATH="$CUDA_HOME/bin:$PATH"
export LD_LIBRARY_PATH="$CUDA_HOME/lib64${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
export OMPI_CXX=/usr/bin/g++-11
make clean
make -j2 CUDA_HOME="$CUDA_HOME" CUDA_ARCH=sm_80
```

切换 CUDA 或架构必须重新编译。上面的 GCC 路径针对已测试的远端环境，先确认该文件存在。

## 本机小网格快速运行

```bash
bash scripts/run_full_resident.sh 3
bash scripts/run_full_resident.sh 100
```

脚本固定使用 nk=2，在 `runs/` 建独立目录，保留原始输入模板；打印的目录内有 `run.log` 和 `output_1/`。它不会运行 nk16。

## A800 单卡 nk16，100 步

在编译完成的项目根目录复制执行以下整段。设置 `nk=2` 可改为小网格。子 shell 结束后不会改变当前终端环境变量和目录。

```bash
(
set -euo pipefail
project=$(pwd)
test -x "$project/EU3D"
nk=16
mkdir -p "$project/runs"
run=$(mktemp -d "$project/runs/a800_nk${nk}_100_XXXXXXXX")
cp -a "$project/input" "$run/input"
sed -i   -e 's/^Final-Time[[:space:]].*/Final-Time 3e-6/'   -e 's/^dt[[:space:]].*/dt 3e-8/'   -e 's/^cfl[[:space:]].*/cfl 0/'   -e 's/^count[[:space:]].*/count 1/'   -e 's/^m_block_x[[:space:]].*/m_block_x 1/'   -e 's/^m_block_y[[:space:]].*/m_block_y 1/'   -e 's/^m_block_z[[:space:]].*/m_block_z 1/'   -e 's/^num_thread[[:space:]].*/num_thread 1/'   "$run/input/ctrl.txt"
sed -i   -e 's/^total_ni[[:space:]].*/total_ni 281/'   -e 's/^total_nj[[:space:]].*/total_nj 141/'   -e "s/^total_nk[[:space:]].*/total_nk $nk/"   "$run/input/grid-3dRSBI.txt"
unset EU3D_VALIDATE_STATE EU3D_VALIDATE_CHAIN EU3D_VALIDATE_PACKED
unset EU3D_VALIDATE_EE_STATE EU3D_VALIDATE_RESIDENT_MUSCL EU3D_VALIDATE_FULL_RESIDENT
unset EU3D_TRACE_TEMP EU3D_DUMP_STATE EU3D_FAST_UNPACK
export EU3D_CHAIN_STATE=1 EU3D_PACKED_OUTPUT=1 EU3D_EE_STATE=1
export EU3D_REUSE_UPLOAD=1 EU3D_RESIDENT_EE=1 EU3D_RESIDENT_MUSCL=1
export EU3D_FULL_RESIDENT=1
cd "$run"
echo "Run directory: $run"
TIMEFORMAT='Wall seconds: %R'
{ time mpirun --allow-run-as-root -np 1 "$project/EU3D"; } > run.log 2>&1
tail -n 15 run.log
if grep -Ei 'Failed|CUDA error|Abort|invalid_nchem=[1-9]|nonfinite=[1-9]' run.log; then
  echo '发现异常，请检查完整日志' >&2
  exit 1
fi
)
```

输入模板应保持 MUSCL_2、EE、Trapezoid-Adaptive 和 H2_JA919；以上命令调整网格与运行长度，不改物理模型。使用独立目录避免覆盖之前的结果。

当前全 GPU 常驻要求单 MPI 进程、固定步长和 DLB 关闭。不要把命令直接改成 `-np 2`；双卡需使用原多卡路径并匹配分块配置。

## 查看结果与验证

在运行目录执行：

```bash
grep -E 'Iteration:|Loop time:|Total Time:|Wall seconds:' run.log | tail -n 5
```

应看到第 100 步和最终时间 `3e-6`。完整输出保存在 `output_1/`。

在项目根目录执行已有正确性回归（需要 Python 3）：

```bash
bash tests/validate_full_resident.sh thin
bash tests/validate_full_resident.sh volume
```

这里 thin 是 281×141×2，volume 是 17×13×4，均会跑 3/100 步及多个对照模式；不是 nk16 验证。验证运行较慢，不拿其耗时作为性能成绩。

最新计时与验证边界见 [最新成绩](最新成绩.md)。`src/` 是实现，`include/` 是接口与开关，`tests/` 是验证，`scripts/` 是运行入口；`archive/` 和项目外 `reports/` 留作追溯。
