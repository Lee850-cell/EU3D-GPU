# 源码导航

建议先看 `src/Main.cpp` → `src/Euler.cpp`，再按模块往下看。

| 文件 | 职责 |
|---|---|
| src/Main.cpp | 程序入口、MPI 初始化与 GPU 绑定 |
| src/Euler.cpp | 总体时间循环、流体/反应调用、验证与状态输出 |
| src/FileReader.cpp | 配置和输入读取 |
| src/Mesh.cpp | 网格与分区 |
| src/Flowfield.cpp | 流场操作、边界、CPU/GPU 流体调用 |
| src/FlowfieldCuda.cu | GPU 重构与通量、上传复用 |
| src/TimeAdv.cpp、src/TimeAdvCuda.cu | 时间推进 |
| src/Reaction.cpp、src/ReactionCuda.cu | 反应、热力学、设备状态更新与数据连接 |
| src/LoadBalance.cpp | 原有负载均衡逻辑；当前配置关闭 DLB |
| src/Function.cpp、src/Global.cpp | 公共函数及全局定义 |
| include/ComputeConfig.hpp | use_cuda、enable_dlb 编译期开关，修改后需重编译 |
| input/ctrl.txt | 时间步、终止时间、算法、MPI 分块等 |
| input/grid-3dRSBI.txt | 当前 RSBI 算例的网格参数 |

`source_manifest.json` 记录初次整理时 src/include/input 的 SHA-256，是原始基线，不是后续改动后的清单。

当前优化入口：`ReactionCuda.cu` 中 `configure_resident_ee_state`、`advance_resident_ee_kernel`、`post_advection_from_ee_host`；`Euler.cpp` 在每次 Computing 开始时重置跨步状态。详见 [跨步状态复用](跨步状态复用.md)。

流体跨步入口：`FlowfieldCuda.cu` 的 `build_resident_muscl` 和 `resident_muscl_*` kernels；`ResidentMusclState.hpp` 是反应阶段发布给流体阶段的只读设备状态视图。详见 [流体输入跨步复用](流体输入跨步复用.md)。

CPU 回填入口：`Euler.cpp` 的 packed output 分支调用 `PackedReactionCopy.hpp`；`EU3D_FAST_UNPACK=1` 启用短行固定长度复制。详见 [反应结果回填优化](反应结果回填优化.md)。

单卡全流程常驻入口：`ReactionCuda.cu` 的 `resident_health_kernel` / `download_resident_output`、`FlowfieldCuda.cu` 的 `resident_front_thermo` 和 `Euler.cpp` 的 `SyncResidentOutput`。详见 [单卡 GPU 常驻](单卡GPU常驻.md)。
