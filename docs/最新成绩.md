# 最新实测成绩

测试日期：2026-10-19。版本：我们的单卡全 GPU 常驻版本。

## 测试条件

- NVIDIA A800 80GB PCIe LC，单 GPU、单 MPI 进程，DLB 关闭。
- 100 步，固定时间步长 `3e-8`，终止时间 `3e-6`；`count=1`。
- MUSCL_2 重构、EE 推进、Trapezoid-Adaptive 化学反应，H2_JA919 机理。
- CUDA 11.8，sm_80，O3；关闭浮点乘加融合。
- 开启状态链、打包输出、EE 状态复用、上传复用、跨步 EE/MUSCL 复用和全 GPU 常驻。
- 关闭对照验证、温度追踪和额外状态导出。

## 最新结果

| 网格 | 步数 | 主循环（秒） | 程序总时间（秒） | 含 MPI 启动退出的墙钟时间（秒） |
|---|---:|---:|---:|---:|
| 281×141×2 | 100 | 2.4096 | 5.34463 | 6.482 |
| 281×141×16 | 100 | 9.0994 | 21.7609 | 22.722 |

两次均正常完成 100 步，未发现运行错误。这是各一次实测，不是多次中位数。此前运行耗时有明显波动，正式报告应在相同环境下重复测试。

完整测试日志保存在本地，不随仓库发布。以上时间取自对应运行日志。

主循环不是纯内核时间，也包含循环中的输出等操作。全 GPU 常驻路径的最终状态回传、输出等工作计入程序总时间；不要仅用主循环代表整个作业耗时。

## 与历史版本的初步比较

同为 A800 单卡、281×141×16、100 步，历史 flux-clear 版本主循环 23.7106 秒、总时间 34.2965 秒。本次对应为 9.0994 秒和 21.7609 秒：主循环约 2.61 倍，总时间约 1.58 倍。

这是历史记录对比，运行环境和波动未严格控制，不能作为正式受控加速比。也不能混用不同 CPU 机器的基准来宣称 60/120 倍。

## 正确性范围

本地全 GPU 常驻回归覆盖 281×141×2 和 17×13×4 两种网格，各 3/100 步；已有最终内部状态比较记录显示优化前后最大绝对差为 0，并检查了中间输出和反应子步历史。边界热力学重算存在浮点末位差异，但通过原严格容差检查。

这次 A800 nk16 运行没有开启对照验证，正常完成不等于已完成该配置的数值等价验证。与原始 CPU 版本曾在 1000 K 热力学分段附近出现严格容差失败，不能宣称全版本结果完全一致。

当前全 GPU 常驻模式只支持单进程。已有多卡路径仍保留，但本页不是双卡成绩；不能直接把本次时间除以二作为双卡结果。
