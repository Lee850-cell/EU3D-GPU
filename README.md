# 我们的 EU3D 求解器

正式代码在 `~/code/mission8/EU3D`，与 `others/lqh` 的第三方实现分开。

- [最新成绩](docs/最新成绩.md)：A800 单卡 nk2/nk16、100 步实测与正确性范围。
- [运行说明](docs/运行说明.md)：本机/远端编译、全 GPU 常驻运行和验证命令。

最新 nk16 单卡实测：主循环 **9.0994 秒**，程序总时间 **21.7609 秒**。这是一次性能运行，不代表已完成该远端配置的数值对照验证。

`src/` 和 `include/` 为当前源码，`input/` 为输入模板，`runs/` 保存独立运行结果。历史日志、来源清单和归档代码保留供追溯。当前全 GPU 常驻模式只支持单进程；多卡使用原路径。
